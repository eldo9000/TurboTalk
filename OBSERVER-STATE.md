## Active development areas
The transcription speed pass that dominated Run 1 has wound down and the focus has shifted in two directions. First, hardening the persistent `whisper-server` lifecycle: re-prewarm on settings save, re-prewarm after a cancel-during-transcription, a yellow "arming" overlay tile while the server is still loading, and an adaptive `audio_ctx` that picks 512 for short utterances and the full 30s window for anything beyond eight seconds. Second, shipping infrastructure: the Tauri updater is now wired end-to-end, and the README header was redesigned for the v0.8.7 prerelease. In flight but unlanded as of this run is an overlay peek-through dimming fix touching `src/Overlay.svelte` and `src-tauri/capabilities/overlay.json`, addressing both a missing-capability silent-throw and a Retina/1×-external coordinate-space mismatch. `docs/INVESTIGATION-LOG.md` has appeared since Run 1 with three entries, all from the TASK-48 CoreML build investigation.

## Fragile / high-risk areas
`src-tauri/src/transcribe.rs` remains the single highest-churn surface and has now absorbed two more rounds of fixes since Run 1: a process-leak/Mac-freeze caused by the static `WORKER` never running Drop on exit (orphaned setsid'd children holding 1.6 GB each), and a triple-paste regression caused by the TASK-47 switch to `whisper-server` quietly losing the anti-hallucination decoding flags from commit `55cfa21`. Both were rooted in the same architectural reality flagged in Run 1 — the sidecar boundary is intricate and easy to regress across refactors. The new overlay work has surfaced a second fragile surface: capability declarations in `src-tauri/capabilities/overlay.json` fail silently in the renderer rather than producing actionable errors, and Tauri's mixed coordinate spaces between `cursorPosition()` and `outerPosition()` only diverge on multi-monitor configurations with different scale factors, which means single-monitor dev sessions cannot reproduce the bug.

## Pattern watch
The "sidecar bootstrap fragility" cluster called out in Run 1 has evolved into a closely related second pattern: refactor-induced flag loss. The TASK-47 cut-over to `whisper-server` silently dropped decoding parameters that had been load-bearing in the previous `whisper-cli` path; the bug only surfaced as triple-paste hallucinations on short or silent audio. Similarly, the TASK-44 `audio_ctx=512` win was benched only on ≤8s utterances and silently truncated longer dictation in production. Both share a shape: a parameter change validated against a narrow scenario regresses an unmeasured one. The new overlay work adds a third instance of the same shape — a missing capability that broke a multi-monitor path while single-monitor worked. No KNOWN-PATTERNS.md exists yet; the patterns live only in commit messages and SESSION-STATUS prose.
